# ITS Strategy

Strategy website for Inference-Time Scaling (ITS) at Red Hat AI Innovation Team.

Internal stakeholder and leadership reference covering vision, results, roadmap, architecture, competitive landscape, and team.

## Deploy

GitHub Pages: Settings > Pages > Source: Deploy from branch > `main` / `/ (root)`

No build step required.

## Update

Edit `index.html` directly. Push to `main`. Site updates automatically.
